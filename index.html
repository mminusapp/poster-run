Poster Run

サポート

このアプリについて

Poster Run は、たくさんの場所を最短の順番で回るための iPhone アプリです。選挙ポスターの掲示場まわりのために作りましたが、ポスティングや配達、訪問まわりなどにも使えます。

使い方

  • 「出発地」で、出発する場所を「住所で設定」か「現在地」で決めます。
  • 「立ち寄り先」に回りたい場所を追加します。「まとめて貼り付け」で、Excel やメモから住所の一覧をまとめて登録できます。地図を長押しして、その場所を追加することもできます。
  • 移動手段（車・バイク・自転車・徒歩・電車）を選んで「最短ルートを計算」を押すと、回る順番と到着予定時刻が表示されます。
  • 「Google マップでナビ開始」で、その順番のまま Google マップのナビを始められます。
  • 回り終えた場所は、丸印を押して「貼った」にします。時刻つきで記録され、「進み具合を報告」で LINE などに送れます。
  • 右上のメニューの「担当分け」では、掲示場の一覧を人数分に分けて、班ごとに送れます。受け取った人は、その文章をコピーして「まとめて貼り付け」に入れるだけで回り始められます。

うまくいかないとき

  • 住所が見つからない — 都道府県や市区町村から書くと見つかりやすくなります。建物名は省いてください。
  • たくさん貼り付けると時間がかかる — Apple のマップの検索回数に制限があるため、途中で少し待つことがあります。そのままお待ちください。
  • 現在地が出ない — 「設定」アプリの「Poster Run」で、位置情報を「このAppの使用中のみ許可」にしてください。
  • 電車のルートが地図に出ない — 電車は所要時間だけで順番を決めます。乗り換えの案内は、Google マップで表示されます。
